# biopentra-storefront 0.5.5

**Rank Math compatibility** — no duplicate frontend SEO output when Rank Math is active.

## What changed

- Technical SEO module defers to Rank Math for meta description, Open Graph, Twitter cards, Organization/WebSite JSON-LD, and BreadcrumbList JSON-LD.
- Unchanged: robots/noindex rules, `robots.txt` tweaks, sitemap exclusions, QA product visibility, attachment alt fallback, canonical helper on noindex pages.

## Install / upgrade

1. Download **`biopentra-storefront-0.5.5.zip`** from this release.
2. Upload via **Plugins → Add New → Upload**, or use **Dashboard → Updates** on production.

## Rollback

Restore **0.5.4** plugin folder from backup.
