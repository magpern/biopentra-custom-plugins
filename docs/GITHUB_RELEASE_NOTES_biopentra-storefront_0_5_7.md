# biopentra-storefront 0.5.7

**Mini-cart product row layout** — visual refinement only.

## What changed

- Larger product thumbnail with rounded corners.
- Title in accent color; variation or short description as subtitle.
- Bold line price; quantity pill on the right; circular remove on thumbnail.
- Tighter, mobile-first row spacing (scoped CSS under `.bp-mini-cart--drawer`).

## Compatibility

- Elementor side-cart fragments unchanged.
- Blocksy qty AJAX and `biopentra_update_mini_cart_qty` fallback unchanged.
- Sticky checkout footer unchanged.

## Install / upgrade

1. Download **`biopentra-storefront-0.5.7.zip`** from this release.
2. Upload or update via Dashboard → Updates (GitHub updater).
3. Clear site/CDN cache if styles do not appear immediately.

## Rollback

Reinstall **`biopentra-storefront-0.5.6.zip`** from the previous GitHub release.
