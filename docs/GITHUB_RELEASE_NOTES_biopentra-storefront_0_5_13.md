# biopentra-storefront 0.5.13

**Soft elevated cart trigger pill** — visual refinement only.

## What Changed

- Restyled the header cart trigger as a compact rounded pill.
- Added an off-white background, subtle border, and gentle hover/focus elevation.
- Refined spacing between cart icon and amount.
- Made amount typography slightly bolder.
- Repositioned the cart count as a smaller red circular badge.
- Added mobile sizing refinements.
- Header-auth module version **1.5.13**; plugin version **0.5.13**.

## Compatibility

- Scoped to mini-cart/header cart selectors only.
- WooCommerce fragments, mini-cart drawer behavior, and Elementor side-cart behavior unchanged.
- Does not modify WooCommerce core, Elementor Pro, Blocksy core, payment gateway plugins, or checkout/cart logic.

## Install / Upgrade

1. Download **`biopentra-storefront-0.5.13.zip`** from this release.
2. Upload via **Plugins → Add New → Upload**, or use **Dashboard → Updates** on production.
3. Clear site/cache layers if header styles appear stale.

## Rollback

Reinstall **`biopentra-storefront-0.5.12.zip`** from the previous GitHub release.
