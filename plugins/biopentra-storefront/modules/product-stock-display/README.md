# Product stock display

Replaces WooCommerce exact stock quantity text on the storefront with configurable labels and colors.

## Hooks

- `woocommerce_get_availability` — single product, variations (`wc_get_stock_html`), and loops using availability HTML.

## Settings

**WooCommerce → Stock display** (requires `manage_woocommerce`).

Does not change admin inventory, cart, or stock reduction.
